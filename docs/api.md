# API Reference

Base URL: local `http://localhost:8000`, production `https://<your-render-service>.onrender.com`.
Interactive docs auto-generated by FastAPI at `/docs` (Swagger UI) and `/redoc`.

All list endpoints return JSON arrays; all data is synthetic/demonstration
data. Confidence and attribution fields are always framed as evidence-based,
never as proof of identity.

| Method | Path | Description |
|---|---|---|
| GET | `/health` | `{"status":"ok","service":"darktrace-ai"}` |
| GET | `/api/actors` | List actors. Query: `q` (search alias), `category`, `status`, `limit` |
| GET | `/api/actors/{id}` | Full actor dossier: aliases, PGP, wallets, onion services, infrastructure, evidence, timeline, relationships |
| GET | `/api/aliases` | List aliases. Query: `actor_id` |
| GET | `/api/pgp` | List PGP identities. Query: `actor_id` |
| GET | `/api/pgp/reuse` | Fingerprints reused across more than one actor |
| GET | `/api/wallets` | List wallets. Query: `actor_id`, `chain` (Bitcoin/Ethereum) |
| GET | `/api/infrastructure` | List candidate infrastructure matches. Query: `actor_id` |
| GET | `/api/onion-services` | List onion services. Query: `actor_id` |
| GET | `/api/relationships` | List relationships. Query: `entity_id`, `type` |
| GET | `/api/graph` | `{nodes, edges}` payload for the relationship constellation view |
| GET | `/api/persona` | List persona-similarity comparisons (labeled `DEMONSTRATION MODEL`) |
| GET | `/api/timeline` | List timeline events. Query: `actor_id`, `category`, `start`, `end` |
| GET | `/api/evidence` | List evidence records. Query: `actor_id`, `reliability` |
| GET | `/api/sources` | List evidence sources with reliability factors |
| GET | `/api/investigations` | List investigations/cases |
| POST | `/api/investigations` | Create an investigation. Body: `{title, description, priority, status}` |
| GET | `/api/scans` | List autonomous scan history |
| POST | `/api/scans` | Start/pause/stop a simulated scan. Body: `{"action": "start"}` |
| GET | `/api/reports/{investigation_id}.json` | Full JSON case report |
| GET | `/api/reports/{investigation_id}.csv` | CSV export (download) |
| POST | `/api/reports` | Generate + log a report. Body: `{investigation_id, format}` |
| GET | `/api/demo/load` | Full curated demo case (`CASE-26151-07`), same shape as `frontend/data.js`'s `DATA` object |

curl http://localhost:8000/api/actors/ACT-001
